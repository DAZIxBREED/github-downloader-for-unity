# Contributing

1. Create a focused branch from `main`.
2. Keep runtime code free of `UnityEditor` references.
3. Add or update EditMode tests for behavior changes.
4. Do not commit GitHub tokens, credentials, downloaded archives, or Unity `Library` data.
5. Preserve Unity 2022.3 LTS compatibility unless a major release explicitly changes the minimum version.
6. Open a pull request describing the behavior, validation performed, and any compatibility impact.
