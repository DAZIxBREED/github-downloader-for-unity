# Changelog

All notable changes to this package are documented here.

## [1.0.0] - 2026-08-06

### Added

- Repository archive downloads by branch, tag, or commit.
- Latest and tagged GitHub release asset resolution.
- Wildcard release asset selection.
- Direct URL downloads.
- Private repository token support.
- ETag and Last-Modified cache revalidation.
- SHA-256 verification.
- Safe ZIP extraction with traversal, symlink, archive-size, entry-count, and compression-ratio protections.
- Optional stripping of a single archive root directory.
- Transactional directory installation with backup and rollback.
- Assets, embedded package, custom directory, download-only, `.unitypackage`, and UPM Git install modes.
- Unity Editor window, project settings page, and token storage.
- Runtime API, tests, documentation, and sample.
